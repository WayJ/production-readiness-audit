# Roadmap / 路线图

## Available in this source package

Nine-dimension skill and rubric; validated score calculator; offline Chinese report UI; English/Chinese documentation and landing pages; fictional examples; standard-library CLI and installer; CI and Pages configurations.

## Candidate next steps, not implemented promises

English report UI; stack-specific evidence checklists; import adapters for selected scanners while preserving human verification; historical report comparison bound to exact snapshots; additional host installation validation; broader browser automation in CI.

## Out of scope

Autonomous production scanning without authorization; automatic fixes/deployment; management ownership scoring; safety certification; replacing project-specific acceptance criteria; guaranteed star growth or production readiness from a score alone.

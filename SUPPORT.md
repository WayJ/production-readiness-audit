# Support / 使用支持

Start with docs/QUICKSTART.md and the scoring/report references in the skill. For reproducible tool bugs, use the bug report form with a minimal **synthetic** input and the exact command, Python version and operating system. Chinese and English reports are welcome.

工具问题请附最小虚构数据、命令、Python 版本、操作系统与实际错误。不要公开客户项目。评分争议应指出具体量表项、预期与证据；“我觉得应该高几分”不足以定位问题。

This is a community project, without a support SLA, promised release date or production approval service. Security-sensitive reports follow SECURITY.md.
